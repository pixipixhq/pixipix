# Security

## Reporting a vulnerability

Report suspected security vulnerabilities through
[GitHub private vulnerability reporting][private-report]. Do not disclose
vulnerability details in public issues or pull requests.

If the reporting form is unavailable, contact the maintainer through GitHub
before sharing details.

To help reproduce the problem, include:

- the PixiPix version, Python version, operating system, and installation method;
- minimal reproduction steps and sanitized configuration;
- the expected behavior, observed behavior, and potential security impact; and
- the smallest synthetic or redistributable fixture that demonstrates the issue,
  if an image is needed.

Do not include credentials, private artwork, proprietary source images, or
personal information in your report.

For ordinary bug reports and contribution guidance, see
[CONTRIBUTING.md](CONTRIBUTING.md).

[private-report]: https://github.com/pixipixhq/pixipix/security/advisories/new
